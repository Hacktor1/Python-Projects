# Analog Clock

A simple **analog clock** GUI built with the `tkinter` library. Displays the current time with hour, minute, and second hands that update every second.

## Features

* **Live Time Display** — Hour, minute, and second hands updated in real-time
* **Clean Design** — Minimalist black-and-white analog face
* **Ticking Second Hand** — Smooth updates every second

## Project Structure

```
analogy-clock/
└── analogy-clock.py     # Main script containing GUI and clock logic
```

## Requirements & Dependencies

1. **Python**: Version 3.x
2. **Library**:
* `tkinter` (usually pre-installed with standard Python installations)

## Setup and Running

1. Run the script:
```bash
python analogy-clock.py
```
