# Personal Finance Dashboard

A **personal finance dashboard** built with `tkinter`, `csv`, and `matplotlib`. Track income and expenses, import/export CSV data, and visualize spending by category with pie charts.

## Features

* **Transaction Tracking** — Add income and expense records with category and date
* **CSV Import/Export** — Save and load financial data in CSV format
* **Category Charts** — Pie charts showing income and expense breakdowns by category
* **Data Table** — All records displayed in a scrollable table view

## Project Structure

```
personal-finance-dashboard/
└── personal-finance-dashboard.py   # Main script containing GUI and logic
```

## Requirements & Dependencies

1. **Python**: Version 3.x
2. **Libraries**:
* `tkinter`
* `matplotlib`

Install the required libraries via terminal/CLI:

```bash
pip install matplotlib
```

## Setup and Running

1. Ensure all dependencies are installed (see above).
2. Run the script:
```bash
python personal-finance-dashboard.py
```
