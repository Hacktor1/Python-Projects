# RGB Color Picker

A simple **RGB color picker** GUI built with `tkinter`. Adjust red, green, and blue sliders to see the resulting color and hex code in real-time.

## Features

* **Live Color Preview** — Large preview panel updates as you adjust sliders
* **Hex Output** — Displays the hex color code for the current selection
* **Auto Contrast** — Automatically switches text color for readability on dark/light backgrounds

## Project Structure

```
rgb-picker/
└── rgb-picker.py   # Main script containing GUI and color logic
```

## Requirements & Dependencies

1. **Python**: Version 3.x
2. **Library**:
* `tkinter` (usually pre-installed with standard Python installations)

## Setup and Running

1. Run the script:
```bash
python rgb-picker.py
```
