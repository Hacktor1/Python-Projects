# To-Do List Application

A **to-do list** GUI built with `tkinter`. Add, complete, and delete tasks with persistent local storage in JSON format.

## Features

* **Task Management** — Add new tasks, mark them as completed, and delete tasks
* **Persistent Storage** — All tasks saved to `tasks.json`
* **Status Indicators** — Visual markers (✓) show completed tasks

## Project Structure

```
todo-list/
├── todo-list.py          # Main script containing GUI and logic
└── tasks.json            # Local database for tasks (auto-created)
```

## Running

1. Run the script:
```bash
python todo-list.py
```
